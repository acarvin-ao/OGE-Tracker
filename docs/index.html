Trades by sector

Outlined cells are sectors the official’s own department regulates, funds or buys from. Select a sector name to see everyone trading in it, or a cell to see that official’s trades.

Sectors come from each company’s SEC industry code. Which sectors a department oversees is set in data/agency_sectors.json and is a judgment call, not an official list. Estimated value uses the midpoint of each reported range.
